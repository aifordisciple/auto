三种架构方案

基于你的偏好：聊天入口、核心先行、混合迭代、渐进验证、可选发现

A

轻量桥接 — 聊天生成 + Forge 审核

聊天中 AI 生成代码和参数，用户确认后点「在 Forge 中打开」。Forge 保持现有形态，新增 AI 侧边面板支持迭代微调。改动最小，最快落地。

B

深度融合 — 聊天即编辑器

重构 Forge：左右双栏。左侧是 AI 对话流，右侧是实时代码预览。对话中生成的代码即时渲染在右侧，无需跳转。点击代码块即可编辑。

C

智能中间层 — Skill Agent 编排

在后端构建专用的 Skill Agent，独立于聊天 Agent。前端只负责展示 Agent 的输出和提供编辑能力。Agent 负责：意图分析→搜索已有→生成→验证→迭代。
