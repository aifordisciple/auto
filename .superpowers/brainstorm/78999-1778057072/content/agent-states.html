Skill Agent 状态机

每个阶段独立运行，用户可随时暂停、修改、跳过、回退

Agent 执行流水线
1
意图解析
~2s
LLM 提取：技能名、领域、输入输出、执行环境
2
相似技能发现 可选跳过
~1s
搜索已有技能，推荐复用/参考。用户选择：基于已有 / 全新创建
3
核心生成 — 代码 + 参数
~10s
LLM 生成 script 代码 + 参数 schema。推送到 ForgeSession，前端即时渲染
4
静态检查
~2s
安全扫描 + 语法检查 + 参数合理性。失败时自动尝试修复（最多 3 次）
5
自动测试 可选跳过
~30s
AI 生成模拟输入 → Docker 沙箱执行 → 检查输出。失败时报告并建议修复
6
输出到 Forge
~1s
写入 ForgeSession + 文件系统。用户进入 Forge 审核、微调、补全、发布

关键交互规则

用户可随时中断

每个阶段完成后 Agent 等待确认。用户可：继续 / 跳过 / 修改后重做 / 进入 Forge 手动编辑

补全按需触发

文档、标签、元数据不在自动流水线中。用户在 Forge 中点击「AI 补全」触发，或聊天中说「帮我写这个技能的文档」

迭代闭环

用户在 Forge 中修改后测试失败 → 错误信息自动送入 Agent → Agent 分析并建议修复 → 用户确认后自动应用。或用户在聊天中说「参数加一个 pvalue 阈值」→ Agent 修改代码并更新 Forge
