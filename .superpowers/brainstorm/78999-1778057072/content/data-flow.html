数据流与 API 设计

Skill Agent 通过 ForgeSession 与前端解耦，流式推送进度

核心数据流
POST /api/forge/agent/generate
{ user_input: "帮我做差异表达分析", chat_context?: [...], base_skill_id?: "existing_skill" }
→ 创建 ForgeSession，返回 session_id + WS 通道
↓ SSE 流式推送 ↓
event: phase
data: {"phase":"intent_parse","status":"done","result":{"skill_name":"差异表达分析","domain":"transcriptomics","executor":"R_env"}}
event: phase
data: {"phase":"similarity_search","status":"done","similar":[{...}]}
event: phase
data: {"phase":"core_generation","status":"streaming","chunk":"def run_de_analysis..."}
event: phase
data: {"phase":"core_generation","status":"done","result":{"script":"...","parameters":[...]}}
event: phase
data: {"phase":"static_check","status":"done","result":{"passed":true,"warnings":[]}}
event: phase
data: {"phase":"auto_test","status":"done","result":{"passed":true,"output":"..."}}
event: phase
data: {"phase":"forge_output","status":"done","forge_url":"/forge/session_abc"}
迭代 API
POST /api/forge/agent/iterate
{ session_id, instruction: "参数加 pvalue 阈值", scope: "params|code|docs" }
→ Agent 修改指定范围 → SSE 推送新的代码/参数
补全 API
POST /api/forge/agent/supplement
{ session_id, supplement_type: "docs|tags|metadata|dependencies" }
→ Agent 生成补全内容 → SSE 推送 → 用户确认后写入

ForgeSession 扩展字段

skill_draft (JSONB) {
  ...existing fields...,
  "agent_phase": "core_generation",   // 当前 Agent 阶段

  "auto_test_result": {...},    // 自动测试结果
  "source_skill_id": null      // 基于哪个已有技能创建的
}
