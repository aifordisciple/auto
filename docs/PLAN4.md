### 2.2 Agent 推理深度 (8.0/10)

**现状分析**:

Agent 采用四轨调度决策树：

```
路径 A [复杂任务蓝图]: 需求复杂、多步骤、有依赖关系 → json_blueprint
路径 B [可执行型 SKILL 调用]: 意图匹配到可执行型 SKILL → json_strategy
路径 C [知识型 SKILL 参考生成]: 意图匹配到知识型 SKILL → 代码块 + json_strategy
路径 D [Live_Coding 实时兜底]: 无匹配 SKILL → 直接生成代码
```

**优势**:
- 决策路径清晰，覆盖全面
- 支持探针工具预检测数据结构
- 策略卡片机制保障用户控制权

**瓶颈**:
| 问题 | 影响 | 严重度 |
|------|------|--------|
| 意图识别规则较简单 | 可能误判用户意图 | MEDIUM |
| Agent 不直接执行代码 | 增加交互轮次 | LOW |
| 蓝图生成缺少进度反馈 | 用户等待焦虑 | MEDIUM |
| 探针工具结果未缓存 | 重复调用浪费 | LOW |

**优化策略**:

```python
# 增强意图识别 (多维度置信度融合)
class EnhancedIntentRecognition:
    def detect_intent(self, user_query: str, context: Dict) -> IntentResult:
        # 1. 规则匹配 (快速)
        rule_result = self._rule_match(user_query)

        # 2. 语义嵌入 (中等)
        embedding_result = self._embedding_match(user_query)

        # 3. 历史偏好 (个性化)
        history_result = self._history_match(user_query, context.get("user_id"))

        # 4. 置信度融合
        final_confidence = (
            rule_result.confidence * 0.4 +
            embedding_result.confidence * 0.3 +
            history_result.confidence * 0.3
        )

        return IntentResult(
            intent_type=self._select_intent(final_confidence),
            matched_skills=rule_result.skills + embedding_result.skills,
            confidence=final_confidence,
            reasoning=self._generate_reasoning()
        )
```

**实施优先级**: P1

// 友好错误消息转换
const ERROR_MESSAGES: Record<string, string> = {
  "ModuleNotFoundError": "缺少必要的软件包，正在尝试自动安装...",
  "FileNotFoundError": "找不到指定的文件，请检查文件路径是否正确",
  "MemoryError": "数据量较大，内存不足。建议：1) 减少数据量 2) 联系管理员扩容",
  "TimeoutError": "执行超时，可能是数据量过大。建议：1) 使用更小的测试集 2) 联系支持"
};

function formatError(rawError: string): UserFriendlyError {
  const errorType = Object.keys(ERROR_MESSAGES).find(k => rawError.includes(k));
  return {
    title: errorType ? "处理中遇到问题" : "执行失败",
    message: ERROR_MESSAGES[errorType] || "请查看详细日志或联系技术支持",
    suggestions: generateSuggestions(rawError),
    rawLog: rawError
  };
}
