
## 全场景交互流转全景推演 (Workflow Instances)

这是针对 **意图1（工作流编排）**、**意图2（代码锻造）** 和 **意图3（显式技能执行）** 的深度全景推演。每个意图下设计了 10 个贴近真实高阶生信分析的流转场景，展示了系统在面对复杂多组学、严格代码规范和动态参数调度时的处理能力。

---

### 第一组：计算、编排与工程场景推演 (1-3)

#### 意图 1：工作流编排意图 (`INTENT_WORKFLOW_ORCHESTRATE`)
**核心规范**：拦截手工硬编码，强制激活对话式 AI 辅助生成向导，生成可执行的 Nextflow 脚本与 `main.nf`。

1. **单细胞与空间转录组联合分析编排**
   * **输入**：“帮我把这批胃癌的 scRNA-seq 数据和 10x Visium 空间数据串起来，先分别做质控和降维，最后用 RCTD 算法做空间反演。”
   * **流转**：L1 拦截到宏观 Pipeline 需求。Orchestrator Agent 接管，在右侧配置栏生成向导。AI 依次与用户确认 scRNA-seq 的过滤阈值、空间切片的对齐参数，最终拼装出包含三个 Process（单细胞处理、空间处理、RCTD 映射）的 Nextflow 脚本。
2. **m6A/m7G 多组学联合鉴定**
   * **输入**：“编排一个表观遗传工作流：把 MeRIP-seq 的 m6A 峰和 m7G 峰结果合并，再结合这批样本的 Bulk RNA-seq 表达矩阵，筛选出甲基化驱动的差异表达基因。”
   * **流转**：Orchestrator Agent 将任务切分为 Peak Calling 汇总、转录本定量和联合统计模型。自动生成对应的 Nextflow Channels，将 BAM 文件和 BED 文件路由到对应的计算进程中。
3. **前列腺癌大队列免疫浸润流转**
   * **输入**：“写个流程，把挂载的 500 个前列腺癌 TCGA 样本走一遍 STAR 比对，然后定量，最后用 CIBERSORTx 跑免疫浸润。”
   * **流转**：识别为重型计算编排。Orchestrator Agent 除了生成 Nextflow 脚本，还联动 System Agent 自动将 Docker 沙箱的执行环境配置为大内存计算节点池（如本地 M3 Ultra 资源池），以支持高并发的 STAR 比对进程。
4. **母胎医学 cfDNA 无创产前检测 (NIPT) 编排**
   * **输入**：“新建一个 NIPT 的变异检测工作流，从 FASTQ 质控到 BWA 比对，再用 GATK 找 SNP，最后输出胎儿游离 DNA 比例评估报告。”
   * **流转**：Orchestrator Agent 调用底层 GATK 最佳实践模板，通过对话向用户确认是否需要开启 BaseRecalibrator（BQSR）步骤，确认后将其编排进主流程。
5. **椎间盘退变 (IVDD) 单细胞轨迹推断流程**
   * **输入**：“把 IVDD 的髓核细胞单独提取出来，走一个完整的拟时序分析流程（Monocle3），并且把每一步的中间态 `.rds` 都存下来。”
   * **流转**：Orchestrator 在生成 Nextflow 代码时，强制为每个 Process 加入 `publishDir` 指令，确保中间产物被正确抛出并挂载到左侧资产面板，供后续随时溯源。
6. **AML (急性髓系白血病) 药物耐药克隆演化**
   * **输入**：“用这批纵向采样的 AML 单细胞突变数据，编排一个从细胞聚类到克隆演化树构建（基于 SCITE）的 Pipeline。”
   * **流转**：由于 SCITE 需要特定的 MCMC 参数，Orchestrator 在向导中强制要求用户确认迭代次数和错误率先验，完成交互后生成完整的演化分析工作流。
7. **WES 肿瘤新生抗原预测**
   * **输入**：“把 HLA 分型工具和 MuTect2 的结果连起来，最后接上 netMHCpan 预测肾癌样本的新生抗原。”
   * **流转**：Orchestrator 梳理出复杂的 DAG 依赖（HLA 进程和突变进程需并行执行，其输出共同作为 netMHCpan 的输入），在 UI 上渲染出 MiniDAG 图供用户检查，确认后投入执行。
8. **宏基因组与代谢组关联分析**
   * **输入**：“16S 的 OTU 表和代谢组的质谱定量表，编排一个双向正交偏最小二乘法 (O2PLS) 的集成分析流程。”
   * **流转**：提取到“16S”和“代谢组”两大通道，Orchestrator 自动引入数据标准化前置处理模块（如 CLR 转换），确保异构数据在进入 O2PLS 统计模块前量纲对齐。
9. **现成 nf-core 流程的动态魔改**
   * **输入**：“导入 `nf-core/rnaseq` 流程，帮我把里面的 STAR 比对器替换成 HISAT2，其他步骤保持不变。”
   * **流转**：Orchestrator 读取 nf-core 源码，不启动手工编辑器，而是通过 AI 语义解析定位到比对模块的子图，将其剥离并替换为 HISAT2 模块，重写输入输出依赖后生成新的 `main.nf`。
10. **多机房分布式调度编排**
    * **输入**：“写个全基因组关联分析 (GWAS) 的流程，质控部分在云端跑，核心的矩阵运算调度到我本地的大内存节点。”
    * **流转**：Orchestrator 在生成 Nextflow 配置时，利用 `process.executor` 和 `process.queue` 指令，实现混合云架构下的节点标签动态分配。

#### 意图 2：代码锻造意图 (`INTENT_SKILL_FORGE`)
**核心规范**：从零编写/重构原子级脚本。必须自带参数系统与默认值；迭代时强制开启“非破坏性更新”，绝对禁止删除历史程序说明和注释。

1. **m7G 甲基化特征序列提取工具**
   * **输入**：“写一个 Python 脚本，根据 BED 文件提取 m7G 峰上下游 100bp 的 FASTA 序列，用于后续 Motif 预测。”
   * **流转**：Skill Forge Agent 介入。生成的代码强制引入 `argparse`，包含 `--input_bed`、`--genome_fasta` 等参数，并设置默认 `flank_length=100`。头部自动生成详尽的 `@ProgramExplanation`。
2. **单细胞自动化注释 R 脚本重构**
   * **输入**：“把我上周写的那个用 SingleR 做细胞注释的 R 脚本优化一下，改成支持多线程并行计算。”
   * **流转**：触发重构。Agent 引入 `BiocParallel` 优化逻辑，但严格触发合规卡点：完整保留了原始脚本中关于“使用何种参考图谱”的所有中文注释行，不发生任何信息截断。
3. **SCI 级定制化热图绘图代码生成**
   * **输入**：“写个用 pheatmap 画肾癌差异基因热图的脚本，要求自带参数控制聚类方法，配色默认用 navy-white-firebrick。”
   * **流转**：锻造代码时除了加入参数系统，自动植入最高级别输出约束逻辑：脚本内部强制包含同时生成 `.pdf`、`.png` 以及保存热图底层聚类坐标数据 `.tsv` 的数据对称性输出代码。
4. **TCGA 临床数据 XML 解析器**
   * **输入**：“写个脚本把 TCGA 下载的那些复杂的临床 XML 文件批量解析成一张扁平化的 TSV 表格。”
   * **流转**：Skill Forge Agent 生成使用 `xml.etree.ElementTree` 的 Python 代码。由于涉及复杂的嵌套解析，系统在关键的 XML 遍历循环处自动生成了高密度的行级业务逻辑注释，方便后续审计。
5. **空间转录组域 (Domain) 鉴定脚本**
   * **输入**：“用 SpaGCN 算法写个识别空间转录组肿瘤边界的 Python 模块。”
   * **流转**：Agent 编写完整的类与方法，暴露 `p` (pixel) 和 `s` (spot) 权重参数并设好默认值，自动完成沙箱内的语法校验和空跑测试（Dry Run），确保模块立即可用。
6. **老旧 Perl 脚本现代化迁移**
   * **输入**：“把左边这个用于转换格式的古老 Perl 脚本，翻译成带类型提示的 Python 代码。”
   * **流转**：Agent 进行跨语言重构。系统不仅完成了语言转换，还将原 Perl 脚本中难以理解的正则逻辑提取出来，在 Python 对应函数上方转化为结构化的 `@ProgramExplanation`。
7. **Drop-out 缺失值深度插补算法**
   * **输入**：“利用现有的 scRNA-seq 矩阵，写一个基于随机游走的缺失值插补 R 算法，设置游走步长参数默认为 3。”
   * **流转**：生成严谨的 R 函数。通过内置的代码审计器，拦截了 Agent 试图硬编码“游走步长”的行为，强制其通过 `optparse` 将步长暴露为外部可调用的命令行参数。
8. **Tauri 桌面应用后端处理模块**
   * **输入**：“为我的生信壁纸 Tauri 桌面应用写个 Rust 后端模块，用于极速读取并解析大型 BED 文件。”
   * **流转**：识别为非 Python/R 的通用跨域锻造。Agent 生成安全的 Rust 代码，附带详尽的内存管理注释，并提供标准化的数据接口与前端通信。
9. **拟时序分析拟合曲线调整**
   * **输入**：“修改现在的 Monocle3 脚本，把发育轨迹的起点强制固定在表达 CD34+ 的造血干细胞上。”
   * **流转**：Agent 在原有代码中追加 `order_cells` 的根节点指定逻辑。触发非破坏性更新卡点：之前的降维参数说明和批次效应去除注释一字不落地保留在最新版本中。
10. **自定义基因集打分引擎**
    * **输入**：“写个 Python 脚本，支持传入任意基因集（GMT格式），使用 UCell 算法对 Anndata 对象进行单细胞级别的打分。”
    * **流转**：锻造脚本并将其封装为一个独立 Skill 资产。系统自动为其生成标准的 `schema.yaml`，以便未来能被 Explicit Skill 节点直接调用。

#### 意图 3：显式技能执行意图 (`INTENT_EXPLICIT_EXEC`)
**核心规范**：调用已封装技能，投入实际算力。L2 层参数提取若发现关键参数缺失，必须挂起路由并使用生成式 UI (Active Probing) 进行拦截追问。

1. **FastQC 大规模批量质控**
   * **输入**：“对左侧那个包含 200 个前列腺癌样本的文件夹跑一遍 FastQC。”
   * **流转**：L1 解构为明确执行动作。L2 从上下文成功提取到输入路径。无需追问，任务直接被挂载到 Docker 暖池沙箱中分布式执行，中栏实时打印 stdout 进度。
2. **Cell Ranger 缺失参考基因组反问**
   * **输入**：“用这批新测的 10x FASTQ 数据跑一下 Cell Ranger Count。”
   * **流转**：L1 识别执行意图。L2 对齐参数系统时，发现致命缺失：未指定 `transcriptome` (参考基因组)。路由挂起，在对话区弹出一个下拉表单供用户选择 GRCh38 或 mm10。用户选择后，沙箱启动。
3. **差异表达分析 (DESeq2) 执行**
   * **输入**：“用我们自己封装的 DESeq2 技能，算一下这个矩阵里肿瘤组和对照组的差异，阈值就用默认的。”
   * **流转**：L1 识别执行。L2 成功匹配底层默认的 `p-adj < 0.05` 和 `log2FC > 1`。任务派发至 R 专属执行容器，计算完成后将差异表格推送到右侧资产面板。
4. **MACS2 峰值调用参数拦截**
   * **输入**：“把这些 ATAC-seq 的 BAM 文件用 MACS2 找一下 Peak。”
   * **流转**：L2 探测到缺失了 MACS2 强制要求的有效基因组大小参数 (`-g` 指令)。触发 Active Probing，弹出包含 `hs`, `mm`, `ce`, `dm` 等选项的表单卡片，阻止了错误参数进入计算队列。
5. **空间转录组细胞分割 (Cellpose)**
   * **输入**：“调用 Cellpose，对这张 H&E 切片进行细胞核分割。”
   * **流转**：L2 匹配参数，发现未指定模型类型。弹出表单让用户在 `cyto` (细胞质) 和 `nuclei` (细胞核) 之间选择，并允许用户滑动滑块调整预估直径 (Diameter)。确认后调用 GPU 节点执行。
6. **ESTIMATE 肿瘤纯度计算**
   * **输入**：“跑一遍 ESTIMATE，评估这批胃癌 Bulk 数据的基质评分和免疫评分。”
   * **流转**：指令及参数完美匹配。系统静默启动 Docker 沙箱运行，实时监控退出码。运行成功退出码为 0，随后前端渲染出一个结果预览的表格组件。
7. **GSEA 基因集富集分析**
   * **输入**：“针对昨天算出的差异基因排序列表，跑一次 GSEA，通路数据库选 KEGG。”
   * **流转**：L1 消解“昨天算出的”为特定的历史 FileID。L2 提取数据库参数为 KEGG。将对应资源挂载进入容器，执行分析并输出富集气泡图及底层 TSV。
8. **Monocle3 轨迹推断模块**
   * **输入**：“对这个处理好的 Seurat 对象跑拟时序分析。”
   * **流转**：L2 检查发现拟时序计算极其耗时且需要较大的内存。路由暂停，系统弹出资源确认提示：“该操作预估需要消耗 32GB 内存及 10 分钟，是否确认在本地高配节点启动执行？”
9. **exomePeak2 甲基化峰鉴定**
   * **输入**：“把这几个 MeRIP-seq 的 IP 和 Input 样本对齐，用 exomePeak2 找一下 m6A 修饰位点。”
   * **流转**：L2 对齐参数，发现缺失了样本配对关系表（Design Matrix）。触发表单交互，要求用户在界面上将 IP 的 BAM 文件与对应的 Input 文件进行配对连线，连线完成后任务下发。
10. **PCA 与聚类基线计算**
    * **输入**：“给这张母胎界面的单细胞矩阵做一个基础的 PCA 和 UMAP 降维聚类。”
    * **流转**：L2 发现未指定 PCA 维度和分辨率。触发 Active Probing，由于是高频操作，系统在弹出的表单中预填了极具生信经验的默认值（Dims=1:30, Resolution=0.8），用户点击一键确认即可运行。

好的，这是针对**意图4（版本与历史控制）**、**意图5（视觉感知与图形管护）**和**意图6（数据探究）**的深度全景推演。这三个意图构成了平台数据可溯源性、视觉表现力和探索性数据分析（EDA）的核心。

### 第二组：视图、状态与探究场景推演 (4-6)

#### 意图 4：版本与历史控制意图 (`INTENT_VERSION_CONTROL`)
**核心规范**：对接底层状态快照树与资产版本控制系统，确保生信分析的绝对可重复性（Reproducibility）和科研审计溯源。

1. **代码锻造历史回滚**
   * **输入**：“把我右侧代码编辑器里的这段 Python 单细胞聚类脚本，回滚到昨天下午加 `argparse` 参数之前的版本。”
   * **流转**：L1 识别为版本控制。System Agent 访问 Git/本地历史树，提取该脚本昨天下午的 commit 快照，并在确认不覆盖现有输出的前提下，将代码热更新至编辑器，同时保留当前的注释不丢失。
2. **分析快照全量恢复**
   * **输入**：“这个胃癌项目的数据被我搞乱了，帮我把整个 Workspace 的状态恢复到跑‘批次效应去除’（Harmony）之前。”
   * **流转**：System Agent 读取底层图数据库（Graph DB）中记录的分析 DAG 状态，自动卸载内存中的现有 `.rds` 或 `.h5ad` 对象，重新挂载批次效应去除前的数据版本，并刷新前端 UI。
3. **多版本分析结果横向对比**
   * **输入**：“对比一下用 resolution=0.5 和 resolution=0.8 跑出来的两次单细胞 UMAP 聚类结果，给我差异报告。”
   * **流转**：L1 识别对比意图。路由至 Data Probe Agent 读取两个对应版本的 FileID，对比其细胞分组元数据（Metadata），并在中栏生成包含 Rand Index 相似度和聚类转移桑基图（Sankey diagram）的对比报告。
4. **历史运行参数溯源**
   * **输入**：“查一下上个月我跑那个 m6A 差异甲基化分析时，用的 p-value 阈值和背景基因集是哪一个。”
   * **流转**：消解时间与项目实体。系统检索底层数据库中该任务的历史执行 Context，返回结构化的参数配置表和当时使用的背景集 FileID。
5. **资产防误删恢复 (Trash Recovery)**
   * **输入**：“我不小心把昨天生成的 GSEA 富集结果表删了，能找回来吗？”
   * **流转**：System Agent 查询对应项目的回收站/软删除记录，定位到该 `.tsv` 文件，撤销删除操作并重新在左侧资产栏中高亮显示。
6. **分析分支创建 (Branching)**
   * **输入**：“基于目前质控好的表达矩阵创建一个新分支叫 'tumor-only'，我接下来的操作只针对肿瘤细胞，不影响主流程。”
   * **流转**：系统在底层创建一个写时复制（Copy-on-Write）的数据集克隆，并在前端工作区切换到新建的 'tumor-only' 状态快照，后续分析完全隔离。
7. **临床审计报告生成 (Audit Trail)**
   * **输入**：“导出这批多中心临床样本从原始 FASTQ 到最终变异位点 VCF 的所有操作和参数变动日志，用于合规审查。”
   * **流转**：梳理该数据资产的整个生命周期节点，生成符合 GLP/GCP 规范的 PDF 审计追踪报告，包含时间戳、执行者、具体参数、Docker 镜像摘要（SHA256）。
8. **跨项目执行复刻 (Pipeline Cloning)**
   * **输入**：“把项目 A 里那套跑得很好的空间转录组参数和流程，一字不差地应用到我现在这个项目 B 的新切片上。”
   * **流转**：提取项目 A 的流程配置文件（`nextflow.config` 及运行参数），将输入通道（Input Channels）重定向为项目 B 的文件，交由 Orchestrator Agent 执行。
9. **环境依赖版本比对**
   * **输入**：“为什么同样的 R 脚本今天跑报错了？对比一下现在的执行环境和上周成功运行时环境依赖包的区别。”
   * **流转**：读取沙箱环境日志，对比两次运行时的 R 包版本列表（`sessionInfo()`），精准指出类似 `SeuratObject` 版本升级导致的 API 弃用问题。
10. **视图微调历史撤销**
    * **输入**：“刚才调火山图颜色改得太乱了，撤销最近的三次调色操作，恢复到默认的 ggsci 方案。”

#### 意图 6：数据探究意图 (`INTENT_DATA_PROBE`)
**核心规范**：旁路计算沙箱，利用高性能探针快速（极低延迟）抽取结构化/半结构化数据的元数据、分布与异常特征，作为下游决策前置。

1. **超大矩阵秒级窥探**
   * **输入**：“看看左侧新传上来的那个 20GB 的单细胞表达矩阵文件，第一行（基因名）和第一列（细胞条码）的格式对不对。”
   * **流转**：识别为探究。Data Probe Agent 不会将文件完整加载入内存，而是利用系统级流读取（如 Unix `head`/`awk`）截取前 10 行/列的样本，在中栏渲染一个轻量级表格预览组件。
2. **临床表型数据合规性与空值检查**
   * **输入**：“检查这批 1000 个 TCGA 样本的临床信息表，看看有哪些列的缺失值（NA/Unknown）比例超过了 20%。”
   * **流转**：探针快速扫描表格，计算各列有效值率。生成一份数据质量诊断报告，明确列出高缺失列（如 `tumor_stage`: 25% NA），建议下游分析将其剔除或插补。
3. **生信特定格式解析与检验 (VCF/BAM)**
   * **输入**：“这个刚比对完的 BAM 文件，参考基因组用的是 hg19 还是 hg38？序列比对率大概是多少？”
   * **流转**：调用底层专有探针（如 `samtools view -H` 和 `samtools flagstat`）。毫秒级提取 Header 信息和比对统计元数据，直接以文本形式回复用户，极大节省时间。
4. **单细胞对象 Meta 信息速查**
   * **输入**：“读取内存里这个 `seurat_obj.rds`，告诉我里面有哪几个 `orig.ident`，每个样本分别有多少细胞。”
   * **流转**：探针通过高效的 R/Python 子进程挂载对象，仅读取对象内的 `metadata` 数据框，进行 `table()` 汇总后返回，不触发高耗时的全局操作。
5. **极值与异常分布探测**
   * **输入**：“在跑差异分析前，看一下这个代谢组学丰度矩阵的数据有没有进行过 Log2 转换。”
   * **流转**：探针抽取矩阵的数值子集，计算全局最大值、最小值和中位数。若最大值在 20-30 之间，智能体客观推断数据极大可能已做 Log 转换，并在前端展示数值分布的轻量级直方图。
6. **分隔符与编码智能识别**
   * **输入**：“刚才合作者发来的那个文本文件，用什么软件都打不开乱码，你看一下结构。”
   * **流转**：Data Probe Agent 运用 `chardet` 及启发式探测算法，识别文件编码（如 GBK/UTF-16）及隐式分隔符（可能是不规范的分号或多空格），并在前端提供转码并规范化为 TSV 的选项。
7. **数据交集预计算 (Venn Probe)**
   * **输入**：“这个表里的差异基因，和上面那个通路集合里的基因，大概有多少个重叠？”
   * **流转**：轻量级探究计算。分别提取两列向量进行 Set 操作，极速返回重叠基因数量与比例（如“共 45 个重叠，占比 12%”），帮助用户决定是否值得继续跑深入的 GSEA。
8. **样本命名规则合规检查**
   * **输入**：“跑流程前，检查一下这两个 FASTQ 文件夹里的样本名是否能一一对应上（R1 和 R2 双端匹配）。”
   * **流转**：探针扫描目录树，运用正则匹配（Regex）检验文件命名连贯性，精准指出诸如 `Sample_1_R1.fq.gz` 缺失对应 `R2` 文件的问题，作为编排执行（Orchestrate）前置的强力防错拦截。
9. **条件分支触发前置判定 (If/Else Hook)**
   * **输入**：“看下这个转录组数据，如果测序深度（Total Reads）中位数低于 1000 万，就打个警告标签，高于的话直接走标准定量流程。”
   * **流转**：结合 L1 解构出的 DAG。Probe Agent 执行前置探测，输出深度中位数为 1250 万。状态机接收该条件结果，顺畅触发 DAG 下游的 Orchestrator Agent 启动标准定量流程。
10. **基因/代谢物 ID 映射体系探测**

#### 意图 8：错误诊断与闭环自愈意图 (`INTENT_DIAGNOSTIC_RECOVERY`)
**核心规范**：监听非零退出码和 Stderr 流。不让用户看满屏红字，直接输出根因分析与补丁策略，实现 Agentic 闭环。

4. **矩阵维度不匹配 / NA 值扩散错误**
   * **输入**：“Python 跑 PCA 时抛出 `ValueError: Input contains NaN, infinity or a value too large...`”
   * **流转**：Diagnostic 联动 Data Probe Agent，快速扫描输入矩阵，确认存在 12 行包含空值。路由至 Skill Forge 生成一段轻量级的 `dropna()` 插补/剔除脚本，插入执行流中。

   * **输入**：“用 A100 跑深度学习模型时报错 `CUDA out of memory`。”
   * **流转**：Agent 读取报错堆栈，自动识别当前 PyTorch 训练的 `batch_size`。提出建议：“显存超载。系统可自动将 `batch_size` 从 64 减半至 32 并开启梯度累加（Gradient Accumulation），是否应用补丁并重试？”
6. **FASTQ / BAM 文件损坏或截断**
   * **输入**：“比对软件报错 `unexpected end of file in ...`”
   * **流转**：Diagnostic 探针调用底层 `md5sum` 和 `gzip -t` 进行文件完整性校验。客观告知用户：“经诊断，`Sample_1_R2.fq.gz` 文件传输不完整（损坏）。请在左侧数据中心重新上传该文件。”

   * **输入**：“R 脚本生存分析报错 `non-numeric argument to binary operator`。”

9. **Nextflow Channel 空载阻塞**
   * **输入**：“Nextflow 流程卡在某个 Process 一直不执行，也不报错。”
   * **流转**：Diagnostic 分析 `.nextflow.log`，发现某一个输入 Channel 是空的。溯源到 Glob 模式 `*.fastq` 没有匹配到文件（实际文件是 `.fq`）。精准指出路径匹配错误并协助修正。
10. **非法字符导致 Shell 注入或路径断裂**
    * **输入**：“样本名为 `Patient A (Control)`，导致 Bash 脚本执行报错 `syntax error near unexpected token '('`。”
    * **流转**：Diagnostic 识别到经典的空格和特殊字符引起的 Shell 转义错误。联动 Skill Forge，在执行前全局注入一个样本名合规化（Sanitization）步骤，将空格和括号替换为下划线。

#### 意图 9 & 10：平台资产调度与团队协作 (`INTENT_SYSTEM_ASSET_OPS` & `INTENT_COLLABORATION`)
**核心规范**：严格的 RBAC 权限控制、Stripe 商业化计费、以及跨用户的资源隔离与分享。

1. **发表级图表与底层数据安全打包分享 (Collaboration)**
   * **输入**：“把这个交互式的 UMAP 聚类图和对应的 TSV 底层坐标文件，生成一个有效期 7 天的分享链接给黄教授，只能看不能改。”
   * **流转**：System Agent 触发分享逻辑。生成一个带 Token 的只读路由视图（View-Only Access），确保被分享者只能查阅图像和下载 TSV 数据，无法反向调度计算节点的算力。
2. **底层计算节点切换与计费查询 (Asset Ops)**
   * **输入**：“接下来的空间组分析很吃算力，把我这台工作区的沙箱切到 16 核 128G 的高配节点，顺便查一下我账号的积分余额够跑多久。”
   * **流转**：对接 K8s API 执行沙箱冷迁移。随后对接 Stripe API 和内部计费模块，返回：“已切换至高配池。当前余额 500 积分，高配节点消耗 10 积分/小时，预估可连续运行 50 小时。”
3. **冷热数据分级存储管理 (Asset Ops)**
   * **输入**：“上个月那个胃癌项目已经发文章了，把项目里所有的中间 BAM 和 FASTQ 文件转移到归档存储，只保留最终的 RDS 对象和代码。”
   * **流转**：System Agent 执行基于正则表达式的文件过滤。调用云存储（如 AWS S3 Glacier/本地冷盘）API 将大文件归档，并在数据库中将项目状态标记为“Archived”。
4. **团队私有技能库发布 (Collaboration)**
   * **输入**：“我刚才重构的这个带详细注释的 m6A 提取 Python 模块很好用，把它发布到我们科室团队的私有技能库里，打上 `Epigenetics` 标签。”
   * **流转**：System Agent 读取 Forge 产出的 `schema.yaml` 和代码文件，修改所有权归属（Owner -> Team），更新知识库索引。其他团队成员可直接通过 `/run-m6A-extract` 调用。
5. **临床医生专属视图授权 (Collaboration)**
   * **输入**：“给外科的李医生开个权限，他只能往这个项目里传临床数据的 Excel，不能看我的原始测序数据，也不能跑代码。”
   * **流转**：调用 IAM (Identity and Access Management) 模块。为特定用户配置 `Upload-Only` 和 `Data-Blind` 角色，生成定向邀请邮件发送给指定医生。
6. **Stripe 积分充值触发 (Asset Ops)**
   * **输入**：“我的计算资源不够了，我要充值 100 块钱积分。”
   * **流转**：System Agent 拦截计费意图，不开启任何沙箱计算。直接在前端界面渲染出 Stripe Checkout 组件或微信/支付宝扫码聚合支付 UI。
7. **大体量公有数据库一键挂载 (Asset Ops)**
   * **输入**：“我要做泛癌分析，帮我把 TCGA 的全部 33 个癌种的标准化表达矩阵挂载到我当前的项目资产里。”
   * **流转**：不执行物理拷贝。System Agent 通过底层符号链接（Symlink）或只读数据卷（Read-Only Volume）将公共大数据库瞬间映射进用户沙箱，做到“秒级挂载”。
8. **执行任务的强制终止与清理 (Asset Ops)**
   * **输入**：“刚才派发的那个多组学比对任务参数设错了，马上停掉它，把产生的垃圾中间文件删干净。”
   * **流转**：System Agent 向底层 Celery Worker / Docker 发送 `SIGKILL` 信号。并联动文件系统，递归删除临时挂载目录下所有时间戳晚于任务启动时的冗余文件。
9. **审计日志 (Audit Trail) 导出与合规审查 (Collaboration)**
   * **输入**：“为了应对期刊的原始数据审查，导出这个项目从创建至今的所有 AI 对话记录、生成的代码版本和数据修改日志，生成 PDF。”
   * **流转**：汇聚图数据库中的操作快照。System Agent 严格按照时间轴编排，生成带有哈希防篡改标记的系统级审计日志报告，满足科研和临床的数据合规要求。
10. **环境镜像持久化打包 (Asset Ops)**
    * **输入**：“我现在的环境里装了很多自定义的 R 包，帮我把当前的 Docker 运行环境打包成一个自定义镜像存下来，下次开机直接用。”
    * **流转**：System Agent 触发底层的 `docker commit` 机制，将用户沙箱层的增量变动（OverlayFS）固化，推送到本地私有镜像仓库（Harbor/Registry），并在用户配置面板中新增该镜像选项。
